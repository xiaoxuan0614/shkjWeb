# 首汇科技官网 SEO 只读扫描与改造方案任务

## 任务目标

对当前已经上线的 Vue 官网做 **SEO 只读扫描和改造方案输出**。

-   官网：https://www.shouhuikeji.com
-   目标搜索引擎：百度、Google、Bing
-   当前阶段：只分析，不修改

核心原则：一套官网、一套 URL、一套 canonical、一套 sitemap、一套 SEO
metadata，同时兼容百度、Google、Bing。只有各搜索引擎的站长平台和 URL
提交方式允许分别实现。
